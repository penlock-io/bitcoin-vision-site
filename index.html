bitcoin-vision is a Rust library with a few small vision models. Give it a photo of a BIP39 recovery phrase or a Penlock share, and it tells you what it read, how sure it is about each word, and what else each word might be.

02 · Models

The models and what they do

These are small models trained for this task, not a general-purpose AI, and they run on the device. Reading a BIP39 phrase uses the first three. Reading a Penlock share only needs the last one.

03 · How it reads

From photo to words

PIPELINE A · BIP39

Recovery phrase

  1. 01Find the words. The page is straightened and each word gets a box drawn around it.
  2. 02Read the letters. The recogniser reads what was actually written, spelling mistakes included.
  3. 03Match against the wordlist. Each word is compared with all 2048 BIP39 words.
  4. 04Check the checksum. The last word of a phrase carries a checksum, which catches most misreads.
  5. 05Ask the user. Words the scanner isn’t sure about are shown to the user with the closest alternatives.

PIPELINE B · PENLOCK

Penlock share

  1. 01Find the share. The share is located in the photo and split into its 72 boxes.
  2. 02Read the symbols. Each box is compared with the 29 symbols Penlock uses.
  3. 03Check each row. Every row has its own error check, so most misreads are caught here.
  4. 04Combine shares. Any 2 of the 3 shares are enough to rebuild the 12 words.
  5. 05Ask the user. If a symbol is smudged, the user can correct it by hand.

04 · Integrate

Using the library

Create a Scanner once and call scan for each photo. For every word you get where it is in the photo, a cropped image of it, the text that was read and the ranked seed words it could be. You also get whether the checksum passed.

use bitcoin_vision::words::{ScanOptions, Scanner};

// feature "bundled-models" embeds the ~24.7 MB of models
let scanner = Scanner::bundled()?; // load once, reuse

let photo = std::fs::read("practice-page.jpg")?;
let document = scanner.scan(&photo, ScanOptions::default())?.document();

for &i in &document.ordered_observations {
    let word = &document.observations[i];
    // word.selected, word.quad, word.candidates
}

  • Hardware wallets

    The models ship with the firmware and the scan happens on the device. A Penlock app has run it on the Passport Prime simulator.

  • Mobile wallets

    The user takes one photo and checks the result instead of typing 12 words. There’s an Android example to start from.

  • Penlock tools

    Read a paper share back without typing 72 symbols by hand, then combine any 2 of the 3 shares.

05 · In a hardware wallet

Tested on the Passport Prime simulator

A Penlock app for Passport Prime, built at a hackathon, uses bitcoin-vision to read shares. It has only run on the Passport Prime simulator so far, not on a real device. Reading Penlock shares needs just the 1.6 MB model, and the library never touches the network, so it fits well on a signing device.

06 · Limits

It’s still a prototype

WHAT IT CAN’T DO YET

  • It only reads English seed words
  • Faint writing, low-contrast photos and unusual page layouts lead to misreads
  • About 1 in 16 wrong 12-word phrases still passes the checksum
  • It isn’t published on crates.io yet

WHAT INTEGRATORS MUST DO

  • Ask the user to confirm every word the scanner isn’t sure about
  • Keep photos and results in memory, never on disk
  • Keep the words hidden until the user taps Reveal, and wipe them on Forget
  • Remind Penlock users to keep their shares in separate places
